ASH INSTRUMENTS - HOW TO RUN ON GOOGLE CHROME (WINDOWS)
=============================================================

[URDU GUIDE / اردو رہنمائی]

آپ نے پوچھا: "کیا میں کچھ مس کر رہا ہوں؟ کوڈ ایکسپورٹ کر کے فائل ایکسٹریکٹ کر رہا ہوں بس۔"

جواب: 
جی بالکل! یہی اصل بات ہے۔
React اور Vite کے پروجیکٹس عام تصاویر یا سادی HTML فائلوں کی طرح نہیں ہوتے کہ زپ ایکسٹریکٹ کرتے ہی ڈائریکٹ ڈبل کلک کر کے چل جائیں۔
جب آپ زپ ایکسپورٹ کرتے ہیں تو اس میں "node_modules" کا فولڈر شامل نہیں ہوتا (کیونکہ اس کا سائز 500 MB سے زیادہ ہوتا ہے)۔
اسی لیے جب آپ بنا کسی چیز کے چلاتے ہیں تو وہ کہتا ہے "vite not found"۔

لیکن اب ہم نے آپ کے لیے کام 100% آسان کر دیا ہے!

★ سب سے آسان طریقہ (اب کچھ بھی انسٹال کرنے کی ضرورت نہیں):
1. نیا زپ ایکسپورٹ کر کے ایکسٹریکٹ کریں۔
2. فولڈر میں موجود "RUN_ON_CHROME.bat" پر ڈبل کلک (Double Click) کریں۔
   (ہم نے اس میں تیار شدہ 'dist' اور ہلکا پھلکا 'serve.cjs' شامل کر دیا ہے، یہ بغیر کسی انتظار کے فوراً Google Chrome میں ویب سائٹ کھول دے گا!)

★ اگر آپ خود کمانڈ سے چلانا چاہتے ہیں:
فولڈر میں CMD کھولیں اور صرف یہ لکھیں:
      node serve.cjs
یہ فوراً Chrome میں http://localhost:3000 کھول دے گا۔

★ اگر آپ کوڈ میں تبدیلیاں (Development) کرنا چاہتے ہیں:
      npm install --legacy-peer-deps
      npm run dev

★ اگر آپ سیدھا انٹرنیٹ پر لائیو دیکھنا چاہتے ہیں (بغیر ڈاؤن لوڈ کیے):
