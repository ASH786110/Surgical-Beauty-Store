# ASH INSTRUMENTS — Official Export & B2B Portal

Premium Surgical & Beauty Implements Manufacturing Portfolio.

## Quick Start on Windows / Mac / Linux

### Windows (1-Click)
Simply double click `RUN_ON_CHROME.bat`. It will automatically install packages with `--legacy-peer-deps`, start the dev server, and open Chrome.

### Manual Setup
1. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```
2. **Start Development Server**:
   ```bash
   npm run dev
   ```
3. **Open in Google Chrome**:
   Navigate to:
   ```
   http://localhost:3000
   ```

## How to Deploy to Production (Vercel / Netlify / Render)
1. **Build Command**: `npm run build`
2. **Output Directory**: `dist`
3. Push to GitHub and import into Vercel or Netlify for free instant global SSL deployment.
